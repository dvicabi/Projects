# Cabessa Social 0.1.0 Beta 1

First personal test build, dated 25 November 2026.

**Android 9+ / ARM64** · Instagram base **456.0.0.53.78** · independent package `com.dvircab.social`.

Includes a stories/messages home, native social actions, Following-only feed with continuation removed, fixed blocking policy, optional grayscale and an independent signing certificate. No external updater, Debug bridge, Ghost Mode or unlock timer is included. The signature-trust compatibility patch was not applied.

## Installation

Download `cabessa-social.apk` from the release assets. Verify SHA-256 against `cabessa-social.apk.sha256.txt`. See the [installation guide](https://github.com/dvicabi/cabessa-social/blob/main/docs/INSTALL_HE.md).

## Verification

15 selected patches applied; 16 automated tests passed in the original build. Signature and alignment verified. **Real-device and runtime-network tests are still pending.** Test with a noncritical account. Modified clients may be incompatible with Instagram or cause account restrictions.
