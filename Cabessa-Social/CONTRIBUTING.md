# Contributing to Cabessa Social

For a bug report include the app version, Android version, device model, steps to reproduce, expected and observed behavior, and sanitized screenshots/logs only. Never include account credentials, session data or signing material.

Keep pull requests focused; describe the change and why it is necessary, update the documentation, and run the applicable tests. Treat the original device-test checklist as a release gate, not as completed testing. Maintain attribution and GPLv3 for the modification source. Do not commit Instagram APKs or private signing material.
